# 04: Inscrição de equipes em torneios

**What to build:** Um usuário consegue montar a lista de participantes de um torneio em rascunho, reutilizando equipes existentes ou criando uma equipe diretamente durante a inscrição.

**Blocked by:** 02 Cadastro completo de equipes; 03 Administração de torneios

**Status:** ready-for-agent

- [ ] Cada equipe pode participar de vários torneios.
- [ ] Uma equipe aparece uma única vez dentro do mesmo torneio.
- [ ] A tela lista equipes disponíveis separadas das já inscritas.
- [ ] É possível criar uma equipe nova e inscrevê-la imediatamente.
- [ ] Inscrições podem ser removidas antes do início.
- [ ] Adição e remoção são bloqueadas após o início.
- [ ] Tentativas de duplicação são recusadas com mensagem clara.
- [ ] As regras de inscrição são testadas independentemente de Flask e HTTP.
