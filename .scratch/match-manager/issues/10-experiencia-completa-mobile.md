# 10: Experiência completa mobile

**What to build:** O usuário consegue navegar e realizar as tarefas principais em celular ou desktop por uma interface simples, bonita e responsiva, com filtros, abas, estados vazios e mensagens claras.

**Blocked by:** 09 Ciclo, correções e encerramento

**Status:** ready-for-agent

- [ ] A página inicial, equipes e torneios seguem uma navegação consistente.
- [ ] Cada torneio apresenta abas de partidas, classificação e equipes.
- [ ] As partidas podem ser filtradas por rodada ou fase e por status.
- [ ] Datas e locais opcionais podem ser informados sem bloquear o resultado.
- [ ] Formulários usam validação compreensível e mensagens em português.
- [ ] Estados vazios, confirmações e erros são visíveis em telas pequenas.
- [ ] A interface usa HTML renderizado no servidor, Jinja2 e CSS próprio mobile-first.
- [ ] Nenhuma interação principal depende de framework JavaScript ou biblioteca de interface.
- [ ] Fluxos principais podem ser concluídos no celular e no desktop.
