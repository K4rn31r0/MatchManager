# 07: Mata-mata: chaveamento

**What to build:** Um usuário consegue escolher a ordem das equipes, sortear opcionalmente, configurar estratégias de bye e visualizar as fases geradas automaticamente.

**Blocked by:** 03 Administração de torneios; 04 Inscrição de equipes em torneios

**Status:** ready-for-agent

- [ ] O usuário pode ordenar as equipes manualmente ou sortear a ordem inicial.
- [ ] Byes são permitidos para completar chaveamentos que não tenham potência de dois equipes.
- [ ] O usuário pode usar ordem manual, sorteio ou prioridade por desempenho para distribuir byes.
- [ ] Uma equipe com bye avança automaticamente sem gerar partida fictícia.
- [ ] A chave gera fases e partidas válidas até a partida final.
- [ ] O torneio não inicia quando o chaveamento não estiver válido.
- [ ] A visão do chaveamento mostra fases, equipes, partidas e vencedores avançados.
- [ ] Geração manual, sorteio e byes são testados independentemente de Flask e HTTP.
